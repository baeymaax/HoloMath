# MRTK HandMenu + GridObjectCollection 單元選單設定指南

## 📋 概述

這個指南將幫助你在 Unity 場景中設定一個手部選單,用來顯示和選擇所有 12 個教學單元。

---

## 🎯 第一步:在 Unity 中建立場景物件

### 1. 建立主選單物件

1. 在 Hierarchy 中右鍵 → **Create Empty**
2. 命名為 `UnitSelectionHandMenu`
3. 設定 Transform:
   ```
   Position: (0, 0, 0.5)
   Rotation: (0, 0, 0)
   Scale: (1, 1, 1)
   ```

### 2. 添加 MRTK 跟隨行為 (Follow Solver)

1. 選擇 `UnitSelectionHandMenu`
2. 在 Inspector 中點擊 **Add Component**
3. 搜尋並添加 `RadialView` (MRTK 的手部跟隨組件)
4. 設定參數:
   - **Tracked Target Type**: `Hand Joint`
   - **Tracked Hand Joint**: `Palm`
   - **Reference Direction**: `Face Camera`
   - **Min/Max Distance**: `0.3 / 0.5`

或者使用簡單的 **Follow** 組件:
   - **Min/Max Distance**: `0.2 / 0.4`
   - **Default Distance**: `0.3`
   - **Orient To Follow Position**: 勾選

### 3. 建立選單容器

1. 在 `UnitSelectionHandMenu` 下建立子物件,命名為 `MenuContainer`
2. 設定 Transform:
   ```
   Position: (0, 0, 0)
   Rotation: (0, 0, 0)
   Scale: (1, 1, 1)
   ```

### 4. 添加背景板 (可選)

1. 在 `MenuContainer` 下右鍵 → **3D Object → Quad**
2. 命名為 `MenuBackground`
3. 設定 Transform:
   ```
   Position: (0, 0, 0.01)
   Rotation: (0, 0, 0)
   Scale: (0.6, 0.8, 1)
   ```
4. 設定材質顏色為半透明深色 (RGBA: 0.1, 0.1, 0.1, 0.8)

---

## 🔧 第二步:設定 GridObjectCollection

### 1. 建立按鈕容器

1. 在 `MenuContainer` 下建立空物件,命名為 `ButtonGrid`
2. 設定 Transform:
   ```
   Position: (0, 0.2, 0)
   Rotation: (0, 0, 0)
   Scale: (1, 1, 1)
   ```

### 2. 添加 GridObjectCollection 組件

1. 選擇 `ButtonGrid`
2. 添加組件: `GridObjectCollection` (MRTK)
3. 設定參數:
   ```
   Surface Type: Plane
   Orient Type: Face Parent Forward
   Layout: Column Then Row
   Rows: 4
   Columns: 3
   Cell Width: 0.18
   Cell Height: 0.12
   ```

這樣可以容納 12 個單元按鈕 (3 列 × 4 行)。

---

## 🎨 第三步:建立單元按鈕 Prefab

### 1. 建立按鈕原型

1. 在 Hierarchy 中右鍵 → **3D Object → Cube**
2. 命名為 `UnitButton_Prefab`
3. 設定 Transform:
   ```
   Position: (0, 0, 0)
   Rotation: (0, 0, 0)
   Scale: (0.15, 0.08, 0.02)
   ```

### 2. 設定按鈕組件

1. 添加 **BoxCollider** 組件 (如果沒有)
   - 勾選 `Is Trigger`: ❌ (不勾選)

2. 添加 **Interactable** 組件 (MRTK)
   - **Selection Mode**: `Button`
   - **Is Enabled**: ✅
   - **Is Toggle**: ❌

3. 添加 **PressableButton** 組件 (MRTK)
   - **Start Push Distance**: 0.002
   - **Max Push Distance**: 0.01
   - **Press Distance**: 0.008
   - **Release Distance on Touch End**: 0.005

### 3. 建立按鈕文字

1. 在 `UnitButton_Prefab` 下右鍵 → **3D Object → TextMeshPro - Text**
2. 命名為 `ButtonText`
3. 設定 Transform:
   ```
   Position: (0, 0, -0.015)
   Rotation: (0, 0, 0)
   Scale: (1, 1, 1)
   ```
4. 設定 TextMeshPro:
   - **Font Asset**: 選擇你的中文字體 (例如: `MSJH_CHT_SDF_4096`)
   - **Font Size**: 3
   - **Auto Size**: ✅
   - **Font Size Min**: 1
   - **Font Size Max**: 5
   - **Alignment**: Center + Middle
   - **Color**: 白色 (255, 255, 255)
   - **Rect Transform Size Delta**: (0.14, 0.07)

### 4. 添加按鈕控制腳本

1. 選擇 `UnitButton_Prefab`
2. 添加 **UnitButtonController** 腳本
3. 在 Inspector 中拖拉組件:
   - **Button Text**: 拖拉 `ButtonText` TextMeshPro
   - **Button Renderer**: 拖拉按鈕本身的 Renderer

### 5. 儲存為 Prefab

1. 將 `UnitButton_Prefab` 從 Hierarchy 拖拉到 Project 視窗
2. 儲存位置: `Assets/HoloMath/Prefab/UnitButton_Prefab.prefab`
3. 刪除 Hierarchy 中的原型物件

---

## 📝 第四步:設定選單標題

### 1. 建立標題文字

1. 在 `MenuContainer` 下右鍵 → **3D Object → TextMeshPro - Text**
2. 命名為 `MenuTitle`
3. 設定 Transform:
   ```
   Position: (0, 0.45, 0)
   Rotation: (0, 0, 0)
   Scale: (1, 1, 1)
   ```
4. 設定 TextMeshPro:
   - **Text**: "選擇單元"
   - **Font Asset**: 中文字體
   - **Font Size**: 5
   - **Alignment**: Center + Middle
   - **Color**: 白色

---

## ⚙️ 第五步:設定 UnitSelectionMenu 腳本

### 1. 添加腳本到主物件

1. 選擇 `UnitSelectionHandMenu`
2. 添加 **UnitSelectionMenu** 腳本

### 2. 設定腳本參數

在 Inspector 中設定:

```
[引用設定]
- Tutorial Manager: 拖拉場景中的 TutorialContentManager_Test 物件
- Unit Button Prefab: 拖拉你建立的 UnitButton_Prefab
- Grid Collection: 拖拉 ButtonGrid 物件
- Button Container: 拖拉 ButtonGrid 物件

[中文字體設定]
- Chinese Font: 拖拉 MSJH_CHT_SDF_4096 (TMP_FontAsset)
- Chinese Font Material: 拖拉 MSJH_CHT_SDF_4096 Material

[顯示設定]
- Auto Populate On Start: ✅ (勾選)
- Normal Button Color: RGB(51, 51, 51)
- Selected Button Color: RGB(26, 153, 230)
- Button Spacing: 0.08

[選單標題]
- Menu Title Text: 拖拉 MenuTitle 物件
- Menu Title: "選擇單元"
```

## 🎮 第六步:整合到現有場景

### 1. 確認 TutorialContentManager_Test 設定

確保你的場景中有 `TutorialContentManager_Test` 物件,並且已經正確設定。

### 2. 添加開啟選單按鈕 (可選)

你可以在現有的 UI 中添加一個按鈕來開啟/關閉選單:

```csharp
public class MenuToggleButton : MonoBehaviour
{
    public UnitSelectionMenu unitMenu;

    public void ToggleMenu()
    {
        if (unitMenu != null)
        {
            unitMenu.ToggleMenu();
        }
    }
}
```

### 3. 或使用手勢啟動

你可以設定手勢來開啟選單,例如:
- 手掌朝向臉部時顯示選單
- 使用手部選單預製件 (MRTK HandMenu Prefab)

## ✅ 第八步:測試與調整

### 1. 播放模式測試

1. 按下 Unity 的 Play 按鈕
2. 使用 MRTK 輸入模擬:
   - **空白鍵 + 滑鼠移動**: 模擬手部
   - **左鍵點擊**: 模擬點選

3. 檢查:
   - ✅ 選單是否跟隨手部
   - ✅ 12 個單元按鈕是否正確顯示
   - ✅ 按鈕文字是否正確顯示中文
   - ✅ 點擊按鈕是否正確載入單元

### 2. 調整佈局

如果按鈕太多或太擠,可以調整 GridObjectCollection:

**3 列 × 4 行** (當前設定):
```
Rows: 4
Columns: 3
Cell Width: 0.18
Cell Height: 0.12
```

**4 列 × 3 行**:
```
Rows: 3
Columns: 4
Cell Width: 0.15
Cell Height: 0.10
```

**2 列 × 6 行** (橫向排列):
```
Rows: 6
Columns: 2
Cell Width: 0.20
Cell Height: 0.10
```

### 3. 調整選單位置

如果選單位置不理想,調整 `RadialView` 或 `Follow` 組件的距離:

```
Min Distance: 0.2 ~ 0.4
Max Distance: 0.4 ~ 0.6
Default Distance: 0.3 ~ 0.5
```

## 🎨 進階自訂

### 1. 添加選單開關按鈕

在 `MenuContainer` 上方添加一個開關按鈕:

1. 複製 `UnitButton_Prefab`
2. 命名為 `MenuCloseButton`
3. 設定文字為 "✕" 或 "關閉"
4. 在 Interactable 的 OnClick 事件中:
   - 選擇 `UnitSelectionHandMenu`
   - 選擇函數 `UnitSelectionMenu.HideMenu()`

### 2. 添加滾動功能 (如果按鈕超過 12 個)

如果未來需要更多按鈕,可以添加 `ScrollingObjectCollection`:

1. 將 `GridObjectCollection` 替換為 `ScrollingObjectCollection`
2. 設定可視範圍和滾動行為
3. 添加滾動條 (MRTK 提供的 Scrollbar Prefab)

### 3. 添加音效

為按鈕點擊添加音效:

1. 在 Interactable 組件中找到 `Audio Events`
2. 設定 `On Click` 音效

## 🐛 常見問題與解決方法

### 問題 1: 按鈕不顯示

**解決方法:**
- 檢查 `Auto Populate On Start` 是否勾選
- 檢查 Tutorial Manager 是否正確參考
- 檢查 Console 是否有錯誤訊息
- 確認 JSON 資料已正確載入

### 問題 2: 中文顯示為方框

**解決方法:**
- 確認已匯入中文字體 (TMP_FontAsset)
- 確認字體材質已正確設定
- 在 UnitSelectionMenu 中設定 Chinese Font 和 Material

### 問題 3: 選單位置不對

**解決方法:**
- 調整 RadialView/Follow 的距離參數
- 確認 Tracked Target Type 設定正確
- 調整 Reference Direction

### 問題 4: 按鈕點擊沒反應

**解決方法:**
- 檢查 Interactable 組件是否啟用
- 檢查 Collider 是否存在且未設為 Trigger
- 檢查 MRTK Input System 是否正常運作
- 檢查 Event System 是否存在於場景中

### 問題 5: GridObjectCollection 沒有更新佈局

**解決方法:**
- 在選單 Populate 後手動呼叫 `gridCollection.UpdateCollection()`
- 或在 Inspector 中點擊 "Update Collection" 按鈕
